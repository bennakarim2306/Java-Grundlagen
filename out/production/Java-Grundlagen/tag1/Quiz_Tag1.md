# Quiz - Tag 1

## Wissensfragen
1. Wie heisst die Einstiegsmethode eines Java-Programms?
2. Wozu dient das Semikolon `;`?
3. Ist `String` ein primitiver Datentyp?
4. Welcher Typ kann nur `true` oder `false` speichern?
5. Was ist der Unterschied zwischen `print` und `println`?

## Mini-Codefragen
6. Waehle einen passenden Typ fuer `9.75`.
7. Was ist an `int alter = "20";` falsch?
8. Ergaenze: `System.out.println("Hallo " + _____);`
9. Warum steht bei `long` oft ein `L` am Ende, z. B. `1000L`?
10. Schreibe eine Zeile, die `Name: Lea` ausgibt.

## Loesungen
1. `public static void main(String[] args)`
2. Es beendet eine Anweisung.
3. Nein, `String` ist ein Referenztyp.
4. `boolean`
5. `println` fuegt einen Zeilenumbruch hinzu, `print` nicht.
6. `double` (oder `float` mit `f`)
7. Typfehler: ein `String` kann nicht direkt in `int` gespeichert werden.
8. z. B. `name`
9. Damit die Zahl als `long` literal erkannt wird.
10. `System.out.println("Name: Lea");`
